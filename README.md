# LETO — NFC-сайт

Мобильная страница для NFC-карты ресторана LETO (Парк Горького, Казань). Чистый HTML/CSS/JS, без сборки.

- Сайт: [https://snrnabi16.github.io/leto-demo/](https://snrnabi16.github.io/leto-demo/)
- Карта: [https://snrnabi16.github.io/leto-demo/card.html](https://snrnabi16.github.io/leto-demo/card.html)

Навигация на хэшах: `#menu`, `#review`, `#book`, `#wifi`.

Wi-Fi и QR на карте — заглушки. Рейтинги на странице отзыва зафиксированы на 17.11.2026.
